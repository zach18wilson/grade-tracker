# Grade Tracker

A simple c++ program that allows users to enter grades and calculate their average, highest, and lowest grades.

## Features
- Allows users to enter multiple grades
- Calculate the average grade
- Identifies the highest and lowest grades

## How to run
1. Compile the program:
```bash
clang++ grade_tracker.cpp -o grade_tracker
```

2. Run the program:
```bash
./grade_tracker
```
